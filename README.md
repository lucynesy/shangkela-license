# 上课啦 · 远程授权配置

这个仓库只放一个东西：`server/config.txt` —— 上课啦改包版的远程授权配置。

## 这个文件管什么

| 字段 | 作用 |
|---|---|
| `expiry` | 到期日。改这里 = 给所有人远程续期，**不用重新发包** |
| `revoked` | 吊销名单。把设备编号写进来，那台手机下次联网就锁死 |
| `updated` | 最后修改时间（给自己看的，程序不读） |

## 怎么改

在 `E:\shangkela\v7\server\` 下执行：

```
python 改配置.py 2026-12-15                    # 只续期
python 改配置.py 2026-12-15 编号1,编号2         # 续期 + 吊销
```

然后推上去：

```
cd E:\shangkela\v7
git add server/config.txt
git commit -m "续期到 2026-12-15"
git push
```

改完约 5 分钟内生效（GitHub 的 CDN 缓存）。

## 注意

- 这个仓库**必须是公开的**，APP 才能免密读取
- 里面只有到期日和设备编号，**没有账号密码**
- 别把构建目录、密钥、APK 传上来
